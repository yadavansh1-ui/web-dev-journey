# JavaScript Day 4 – Arrays

## 1. What is an Array?

Array stores multiple values in one variable.

Example:

```javascript
let fruits = ["apple", "mango", "banana"];
```

---

## 2. Indexing

Array positions start from 0.

Example:

fruits[0]

---

## 3. push()

Adds element at end.

---

## 4. pop()

Removes last element.

---

## 5. unshift()

Adds element at beginning.

---

## 6. shift()

Removes first element.

---

## 7. splice()

Can:
- add
- remove
- replace

Syntax:

splice(start, deleteCount, newValue)

---

## 8. slice()

Extracts portion of array.

Does not modify original array.

---

## 9. concat()

Joins arrays together.

---

## 10. join()

Converts array into string.

---

## 11. reverse()

Reverses array.

---

## 12. sort()

Sorts values.

Important:
numbers.sort() can behave unexpectedly for large numbers.

---

# IMPORTANT ARRAY METHODS

## 13. forEach()

Loops through array.

Used for displaying data.

---

## 14. map()

Creates new transformed array.

Very important.

---

## 15. filter()

Returns filtered values.

Example:
products above price.

---

## 16. find()

Returns first matching value.

---

## 17. some()

Checks if at least one value matches.

Returns:
true / false

---

## 18. every()

Checks if all values match.

---

## 19. reduce()

Reduces array to single value.

Examples:
- total price
- marks sum
- cart total

---

## 20. Important Understanding

Arrays are one of the most used concepts in JavaScript.

Master:
- map
- filter
- reduce

These are heavily used in React too.

---

## 21. Quick Revision

push → add end  
pop → remove end  
map → transform  
filter → filter values  
reduce → single result  

---

## 22. One Line Understanding

Arrays help JavaScript manage collections of data efficiently.
