# JavaScript Day 1 – Basics

## 1. What is JavaScript?

JavaScript is a programming language used to make websites interactive.

Examples:
- button clicks
- animations
- form validation
- dynamic content

---

## 2. How JavaScript Works

Browser reads JavaScript using a JS engine.

Example:
Chrome → V8 Engine

---

## 3. Script Tag

Used to connect JavaScript file.

Example:

<script src="script.js"></script>

Usually added before closing body tag.

---

## 4. console.log()

Used to print output in browser console.

Example:

console.log("Hello");

---

## 5. Comments

Single line:
```javascript
// comment
```

Multi line:
```javascript
/* comment */
```

---

## 6. Variables

Variables store data.

### var
Old way.
Function scoped.

### let
Modern way.
Can change value.

### const
Value cannot be reassigned.

---

## 7. Data Types

### String
Text data.

```javascript
let name = "Ansh";
```

### Number

```javascript
let age = 21;
```

### Boolean

```javascript
true / false
```

### Undefined

Variable declared but no value.

### Null

Intentional empty value.

---

## 8. typeof

Used to check data type.

Example:

typeof "hello"

---

## 9. Operators

Arithmetic operators:
- +
- -
- *
- /

---

## 10. Type Conversion

Manual conversion.

Example:

Number("100")

String(50)

---

## 11. Type Coercion

JavaScript automatically converts values sometimes.

Example:

"5" + 1 → "51"

"5" - 1 → 4

---

## 12. Input / Output

### alert()

Shows popup.

### prompt()

Takes input from user.

### confirm()

Returns true or false.

---

## 13. Quick Revision

console.log → output  
let → changeable variable  
const → fixed variable  
typeof → checks type  

---

## 14. One Line Understanding

JavaScript adds logic and interaction to websites.
